# HTK LABS — Official Website

**Build. Automate. Grow.**

Professional website for HTK LABS — a digital solutions company helping businesses create, automate and grow their digital presence.

## Technology

- **React 18** — UI components
- **Vite 6** — Build tooling
- **CSS Custom Properties** — Design token system
- **No UI frameworks** — Hand-crafted CSS

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Project Structure

```
src/
├── components/     # All React components (sections + UI)
├── hooks/          # Custom React hooks
├── data/           # Centralized site content and configuration
├── main.jsx        # Application entry point
├── App.jsx         # Root component
├── App.css         # Root layout styles
└── index.css       # Design tokens, reset, global styles
```
